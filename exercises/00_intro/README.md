# Intro

TypeScript is JavaScript with types. You write the same code you'd write in JavaScript, plus
annotations such as `name: string`, and the TypeScript compiler checks the whole program
before it runs. Mistakes that JavaScript only reveals at runtime, like a misspelled property
or a function called with the wrong arguments, become errors in your editor.

Node runs TypeScript files directly by erasing the types, so the code that runs is exactly
what you wrote, minus the annotations.
